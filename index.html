Deploy Container
Quick add:

One per entry: PORT, PORT/udp, or HOST:CONTAINER/udp. Bedrock and Simple Voice Chat are UDP. Docker fixes bindings when the container is created, so these cannot be added to a server later.

Leave 24454/udp or 19132/udp at their default numbers and a busy port is moved to the next free one automatically, with the server's own config updated to match — clients are told the new number during the handshake. Write an explicit HOST:CONTAINER/udp mapping to place it yourself instead.

Duplicate

Copies mods, plugins, config, the pinned server jar and the world's datapacks. The world itself is not copied — the clone generates a fresh one and the datapacks are replanted into it. Voice chat and Bedrock ports are carried over, shifted to free numbers if the originals are busy.

The source server is never modified.
